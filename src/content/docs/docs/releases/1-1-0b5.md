Released on 2026-11-09, on top of [1.1.0b4](../1-1-0b4/). This is the current
beta. Install or upgrade:

```bash
uv tool install --force "nexus-scholar>=1.1.0b5"
nexus-scholar --version   # nexus-scholar 1.1.0b5
```

Do not install with `--prerelease allow` (see [1.1.0b4](../1-1-0b4/)).

## What changed for you

- **Create a workspace from the browser.** On Workspaces, "New review" opens
  the inception screens: Drafts, then Scope, Shape, Concepts and criteria,
  Review, Done. Every save is checked against the draft's last update, so a
  second tab cannot overwrite it silently. The engine's leaning, recommended
  playbook and research-question template are shown as drafts; nothing is
  applied until you choose it. Screening criteria appear verbatim with their
  source; a criterion the wizard wrote needs your explicit Accept. Review writes
  nothing until you press Create. The screens are in English, French and
  Arabic.
- **Re-inception no longer overwrites a live protocol.** The terminal wizard,
  `nexus-scholar init` and the browser flow refuse a folder that already holds
  a workspace unless you ask to replace it; the old protocol files are backed
  up, and the journal names the old fingerprint. A workspace with screening
  decisions needs a further explicit confirmation.
- **Triage is a focus screen on desktop.** At 1024 px and wider, the site
  header, step bar and footer give way to one triage bar with progress, the
  queue (J and K), help and a way out; a counts rail sits on the left. The
  checklist is optional and starts collapsed: include needs no answers,
  exclude needs only a reason.
- **PubMed `.nbib` import.** Import accepts a PubMed MEDLINE export (Send to →
  Citation manager) beside RIS. The format is chosen by file extension, then by
  the first line. RIS and `.nbib` files from different databases are
  deduplicated together. Not yet tried on a real PubMed download: the test
  fixture is hand-written.
- **Searches are honest about what they fetched** (terminal only, no screen
  yet). Each database records the query it ran, the total it reported, how
  many records it returned, the cap and whether the cap was hit, and a PRISMA-S
  report is written per run. A live search needs a real contact email: the old
  placeholder is gone, and a search refuses with `MAILTO_NOT_SET` before
  sending a request. Record ids no longer depend on input order. A DOI that
  matches a different title is flagged, never swapped. The terminal run now
  builds the corpus snapshot, so screening is reachable from a fresh run.
- **Reconnaissance over HTTP.** The grounded search that backs inception runs
  in the console as well as in the terminal wizard and the MCP tools, on one
  shared engine.
- **Three fixes.** The retriever embeds its own queries, so a query no longer
  tries to download a default model; the inception step bar no longer triggers
  a hydration error; and "Use this draft as a research question" on Shape
  cannot insert a stale or blank sentence.

## Existing workspaces

Nothing in an existing workspace changes. A protocol without the new optional
retrieval-cap key keeps its exact fingerprint.

## For anyone calling the local API or the tools

New routes under `/api/v1/inception` (drafts, steps, preview, genesis, and the
reconnaissance jobs). New refusal codes include `WORKSPACE_EXISTS`,
`SCREENING_BOUND`, `STALE_BINDING`, `MAILTO_NOT_SET`, `DRAFT_CONFLICT` and
`POOL_TOO_SMALL`. `criteria` is optional on a triage decision. The test suite
now refuses any network connection unless `NEXUS_ALLOW_NETWORK=1` is set.

## Known limits

The limits of [1.1.0b4](../1-1-0b4/) and the [known limits page](../../known-limits/)
still apply, plus these:

- Explore and Direction (reconnaissance) have no screens yet.
- There is no screen for Discovery (searching databases); searching is by
  terminal, and you import RIS or `.nbib` files in the app.
- Creating the workspace is not bound to the previewed protocol: a save from
  another tab between Review and Create goes through unseen.
- A draft cannot be discarded from the browser.
- Still parked: synthesis, the evidence matrix, the citation graph and
  risk-of-bias trust.
