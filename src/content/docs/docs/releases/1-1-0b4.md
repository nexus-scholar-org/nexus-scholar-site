An install fix for [1.1.0b3](../1-1-0b3/), released on 2026-11-08.
Superseded by [1.1.0b5](../1-1-0b5/) and [1.1.0b6](../1-1-0b6/).

## What changed

- **The app starts after any install.** Installing 1.1.0b1 to b3 with
  `--prerelease allow`, as the documentation used to say, pulled a development
  release of a dependency that drops one of its own dependencies. The app then
  stopped at start with `No module named 'httpcore'`. 1.1.0b4 bounds that
  dependency below 1.0 and declares the missing package itself, so even that
  command now works.
- **The documentation installs with a version** (`"nexus-scholar>=1.1.0b4"`)
  instead of `--prerelease allow`, so only Nexus Scholar may be a beta.

Nothing else changed. The features and the local API are those of
[1.1.0b3](../1-1-0b3/).

## If 1.1.0b3 or older does not start

```bash
uv tool install --force "nexus-scholar>=1.1.0b6"
```

Your workspaces are untouched: the failure happened before the app read
anything.
